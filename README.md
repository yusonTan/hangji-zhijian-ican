# 航迹智判｜AIS 航迹异常识别与风险研判智能体

2026 年 iCAN 大学生创新创业大赛 AI 无代码智能体挑战赛 DuMate 智能体应用创新赛题参赛作品的公开 Web 演示。

- 支持内置合成案例和 NOAA 2018 公开 AIS 案例。
- 展示数据质量检查、R8 因果轨迹预测、轨迹可视化、R1–R8 异常证据、风险分级与规则参数。
- 提供对话式风险解释和 Markdown / CSV / JSON 报告下载。
- 公网静态版不上传用户数据；自有 CSV 的完整分析由提交包内本地版执行。

免责声明：本项目仅用于教学、科研与竞赛演示，不构成任何海事安全决策依据。

本项目包含 AI 辅助制作内容。
